A model that plays Snake by reading. Before every move the game describes each option in a plain
sentence, and the model picks the one most likely to go well. It never sees the board.

- It shows a small model can make real decisions from written descriptions alone
- The same idea works for any decision you can put into words, like checking a document, sorting an item or choosing what a person should look at
- It says how sure it is about each move, so the same setup can hand its unsure calls to a person
